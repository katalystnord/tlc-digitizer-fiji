Quantitative TLC analysis from a single photograph.

TLC Digitizer takes one photo of a developed thin-layer chromatography plate — smartphone or flatbed scanner — and returns Rf values, integrated spot intensities, and calibration-derived concentrations, with every analysis parameter logged to a reproducible CSV.

How it works

An eight-stage pipeline, directly derived from the peer-reviewed TLCyzer algorithm (Hauk et al., Scientific Reports 2022), with additions from the qTLC and qtlc literature.

01

Image preparation

Luminance or green-channel greyscale conversion.

02

Perspective correction

Hough-detected corners, homography warp to a rectified plate.

03

Background correction

Quartic polynomial, white top-hat, or Savitzky-Golay.

04

Reference lines

User marks origin and solvent front to define the Rf axis.

05

Spot detection

Centroid, radius and Rf per spot — four selectable methods.

06

Integration

Top-15% intensity sum per spot, robust to edge noise.

07

Calibration

OLS regression on ≥3 references; reports R², LOD, LOQ.

08

CSV export

Every parameter logged — results are fully reproducible.

Detection methods

Step 5 offers four strategies as a single-choice option. Legacy is the default and the only method currently validated against reference plates — the rest are opt-in and explicitly labelled beta in the UI.

Legacy (mean threshold) Validated

Fixed circular ROI from mean-threshold connected components. Recommended default.

Shape-aware detection Beta

Hysteresis linking + watershed peak separation — integrates a spot's true connected shape, better for streaking or tailing lanes.

Lane detection Beta

Continuous-wavelet-transform lane-boundary detection, independent of spot detection — can represent a genuinely empty lane.

Advanced detection (Labkit) Beta

Random-forest pixel classifier trained from a handful of user-marked regions per image — strong on faint spots and tailing lanes.

Validation

Leave-one-out recovery and RSD against the three supplementary reference plates from the TLCyzer paper (legacy detection, n = 15 spots total).

Honest framing: this is one published, small dataset (3 plates, 15 spots), and it stays inside the TLCyzer paper's own 96.8–103.9% recovery band — but n=15 leaves real room for overfitting, and MOESM3's RSD is known to be threshold-sensitive. The project's own next step is a systematic parallel benchmark against the reference TLCyzer app, followed by a call for fresh, purpose-collected plates — not further tuning against these same three images.

Installation

Option A — Fiji update site (recommended, once published)

  1. Open Fiji
  2. Help → Update → Manage Update Sites
  3. Add the TLC Digitizer update site (URL to be confirmed on publication)
  4. Click Apply changes and restart Fiji

Option B — Manual JAR install

  1. Download tlc-digitizer-X.Y.Z.jar from GitHub Releases
  2. Copy it into your Fiji plugins/ folder
  3. Restart Fiji

Runs as Plugins → TLC → TLC Digitizer. Build from source:

git clone https://github.com/katalystnord/tlc-digitizer-fiji.git
cd tlc-digitizer-fiji
./mvnw package
